# Croft browser prototype references

13 November 2026. Live read-only Mobbin search returned Notion web previews in this session. The images below were inspected in the connector. Mobbin imagery and example content are reference material. Croft uses its supplied mark and synthetic workspace data.

## Minimal workspace pass

The latest live searches covered the workspace sidebar, a blank page, and appearance. These are the visual references for the minimal Croft interface. The tables and galleries below document the earlier prototype.

| State | Visible details | Croft mapping |
| --- | --- | --- |
| Blank document | The pale rail takes about 18% of the 768 px preview. The main pane has a thin top bar, a muted New page heading, open space and a row of small starter actions. [Blank Notion page](https://mobbin.com/screens/8a1f646f-da51-4baa-a89d-489e6e7035a5) | Croft uses a slim top bar and a centred welcome with a short list of recent sample pages. The light sidebar is white by request. |
| Workspace menu | A small menu opens directly below the workspace name. A compact header and faint dividers separate short groups. An icon and check mark identify the current workspace. [Notion workspace menu](https://mobbin.com/screens/eb0b0242-8e97-41c0-b2b0-f7446a6f7b3c) | Croft carries over the short icon-and-label rows and subtle selected state. Its fixed sidebar header shows the Croft mark and a collapse control. |
| Appearance | The preferences pane places the theme label on the left and the choice on the right. The open dropdown fits system, light and dark in a short checked list. [Appearance row](https://mobbin.com/screens/878083d9-f5bf-4a48-80c4-5fb59814524d) · [Open theme menu](https://mobbin.com/screens/6c6b018e-3227-461b-8426-4bdb502bc2e1) | The two-pane Settings dialog uses right-aligned controls and a short checked list of Croft themes. |

The reference images establish visible placement, size and hierarchy. See [the QA report](QA.md) for keyboard and dismissal checks in Croft.

[Workspace document](https://mobbin.com/screens/f2dcf700-2fe5-4633-a706-e0391c025432) | Compact navigation and hierarchy, restrained chrome, and a centred document column. |

[Board grouped by status](https://mobbin.com/screens/f1724632-5d42-47ff-96cc-7884f9733a00) | Colour-matched status chips and lanes, compact record cards, and a create action within each group. |
| Calendar | The seven-column month grid carries small weekday labels, a top-right date in each cell, softer shading outside the working days, and a circle for today. The top controls put the month on the left and Today with navigation arrows on the right. Multiple compact cards fit in a dated cell. [Calendar month](https://mobbin.com/screens/5b3dd0a5-2981-487b-9510-c7d46f221c53) | Quiet grid dividers and compact date-linked records. Keep month navigation close to the grid and use a small accent for today. |
| Gallery | Three gently rounded cards fit across the database pane. Each photographed card contains a roughly 16:9 cover over the name and a vertical property stack. A blank cover and outlined New page tile sit in the next row. [Gallery](https://mobbin.com/screens/0bd76f5f-9281-4d76-933e-cafe385ef965) | A responsive grid with a consistent cover height, short metadata and clear boundaries. Use original local artwork or a simple placeholder when a record has no cover. |
| Workspace search | A white overlay near the top takes about two-thirds of the viewport width. The search input and filters sit above recent results grouped by date. The selected row has a soft highlight and a page preview to its right. [Recent pages search](https://mobbin.com/screens/b1273bdd-d65d-44be-a422-ffc0f601bacd) | Put focus into search immediately and keep rows compact. Use visible selection and render recent pages or matching results in the same surface. |
| Preferences | The working area dims beneath a large modal. A slim left column groups settings. The right pane uses label-and-control rows, with section headings and fine separators. The appearance control opens a short menu for system, light and dark. [Light preferences](https://mobbin.com/screens/6c6b018e-3227-461b-8426-4bdb502bc2e1) | Two-pane settings with compact groups and predictable controls for each prototype preference. |

## Prior handoff and documentation

- The earlier desktop reference pass inspected selection and slash-menu previews. The formatting toolbar sits near the selected text. Slash commands occupy a compact menu next to the active block, grouping commands by type. Croft can use the same anchor and density. The screenshot shows the rendered menu, and Notion's keyboard guide documents its `/` and Escape actions. [Document selection](https://mobbin.com/screens/789e9836-c03b-4fb7-a80e-85a38e06d857) · [Slash menu](https://mobbin.com/screens/8cbe99a8-57a4-40e6-85c8-5f55712b6cf3) · [Notion keyboard shortcuts](https://www.notion.com/help/keyboard-shortcuts#slash-commands)
- A separate live Home search returned a database dashboard, with adjacent table, chart and timeline panels. Notion's current documentation places Home in the sidebar, with sections such as Recents and Favourites. The prototype's full-page Home is a Croft layout informed by those workspace patterns. The dedicated Home layout is a design choice, with no direct Mobbin match in these searches. [Database dashboard](https://mobbin.com/screens/41f32a46-0aa4-4205-a6ab-627135308029) · [Notion sidebar](https://www.notion.com/en-gb/help/navigate-with-the-sidebar)
- Notion documents switching views on the same database, grouping Board by status and Calendar by date. Its view settings cover per-view filters, sorts, grouping and page opening. The visible prototype behaviours should be checked on the running browser app. [Database views](https://www.notion.com/help/views-filters-and-sorts) · [Creating a database](https://www.notion.com/en-gb/help/create-a-database)
- The earlier project research includes dark preferences, both database creation flows, search and editor keyboard behaviour, and links for states that remain unverified. The handoff separately records a confirmation sheet layered above preferences.
